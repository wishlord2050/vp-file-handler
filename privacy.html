VP File Handler – Privacy Policy

Last updated: October 29, 2026

VP File Handler is a desktop app for renaming, copying and moving files on your own PC. This policy explains what the app does with your information.

Information we collect

None. VP File Handler does not collect, store, send or sell any personal information. It has no accounts, no analytics, no advertising and no tracking.

Your files

VP File Handler only reads the folders and the Excel / CSV name lists that you choose. All work happens on your PC. File names, file contents and folder paths never leave your computer.

Data stored on your PC

VP File Handler saves your settings (theme, extension list, options), a record of your last rename so it can be undone, and an error log. In the free Lite edition it also keeps a count of today's runs (in the app folder and in your Windows user registry). This data stays on your PC and is removed when you uninstall the app.

Internet access

The only internet use is asking the Microsoft Store, through Windows, whether a newer version of the app is available. No personal information or file data is sent. The "Contact support", "Send a suggestion" and "Privacy policy" buttons only open your own email app, web browser or the Microsoft Store app.

Purchases

Purchases are handled by the Microsoft Store. We do not receive your payment details. See the Microsoft Privacy Statement.

Children

VP File Handler does not knowingly collect information from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
